# Chip Creative Studio Skills

A centralized collection of open-source skills and workflows for Chip Creative Studio OS.

## Source Repositories

- Marketing Skills: https://github.com/coreyhaines31/marketingskills

## Purpose

Use these repositories as reference sources for marketing strategy, creative research, brand development, and professional workflows.

Do not assume that listing a source repository makes its contents available. Only use skills whose files are present in the connected repository or otherwise accessible.
